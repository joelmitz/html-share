# 脅威モデル（Cloudflare版）

## 守るもの

- 成果物HTMLに含まれる業務情報
- 本人用ダッシュボードとレビュー回答
- 共有URL署名用の秘密鍵
- ペアリング済み端末トークン
- 利用者のCloudflareアカウントと利用料金

## 想定する脅威

### 悪意ある成果物HTML

AIが生成したHTMLや外部から受け取ったHTMLには、意図しないJavaScriptが含まれる可能性があります。成果物は管理面と別オリジンへ置き、Accessセッションとレビュー APIから分離します。閲覧面にはサンドボックス付きCSPを適用し、外部通信、フォーム送信、フレーム埋め込み、別画面への遷移を制限します。画像・フォント・音声などはCLIが許可ディレクトリから単一HTMLへ埋め込みます。

### 共有URLの流出

共有URLを知る人は有効期限まで閲覧できます。無期限URLは発行せず、利用者が設定した上限を超える期間も拒否します。URLはログ、チャット、画面共有へ残り得るため、機密性の高い内容には共有URLを使わないでください。

### 秘密鍵の漏えい

秘密鍵はGit管理外とし、ローカルと console Worker の secret にだけ置きます。閲覧面（content Worker）へは公開鍵しか配布しないため、閲覧面が侵害されても署名は偽造できません。漏えい時は `html-share keys init --overwrite` と `html-share keys store --overwrite` で鍵ペアをローテーションします。

### Access設定の誤り

管理面の認証はCloudflare Accessに委ねますが、console Worker 側でも `Cf-Access-Jwt-Assertion` の署名・audience・発行者・オーナーメール一致を独立に検証します。Accessアプリの対象パスを誤って外しても、オーナーAPIと管理画面は開きません。workers.dev は無効化し、カスタムドメイン経由以外の到達経路を持ちません。

### ペアリングコードの総当たり

コードは40ビットの暗号学的乱数から生成し、10分で失効し、一度だけ利用できます。公開環境で追加の総当たり対策が必要な場合は、Cloudflare WAFのレート制御ルールを追加してください。

### 意図しないファイルの配信

設定されたルートディレクトリ以外は読みません。`realpath`でシンボリックリンクの実体も検査します。ローカル参照は許可された拡張子とサイズだけを単一HTMLへ埋め込みます。

### Cloudflare費用の悪用

作者が運営する共通基盤はありません。各利用者のCloudflareへデプロイします。タスクは90日、ペアリングコードは10分で失効し、遅延削除します。公開運用ではWorkersの利用状況通知と、必要に応じたレート制御を推奨します。

## 対象外

- 侵害済みの利用者端末またはCloudflare管理者アカウント
- 共有URLを受け取った正規閲覧者によるスクリーンショットや再配布
- 利用者がCSPを無効化して配信した独自コンテンツ
